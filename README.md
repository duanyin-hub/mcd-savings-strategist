# 麦麦省钱军师 · 点单前的最后一道算术

> 2026 1024 程序员节 · 麦当劳程序员创意开发大赛参赛作品
> 基于 McDonald's China MCP 开发 | 用 WorkBuddy 全程开发

## 这是什么

市面上比价工具很多，但都有一个共同问题：**它们只告诉你"这张券多便宜"，不告诉你"这一单到底怎么点最划算"**。

麦麦省钱军师把一次点单决策拆成三层账：

| 层 | 回答的问题 | 调用的 MCP 工具 |
|---|---|---|
| ① 促销层 | 这单本身有什么满减/折扣可吃 | query-promotions |
| ② 券层 | 我手里的券哪张用在这单最值 | query-store-coupons + query-my-coupons |
| ③ 实付层 | 组合后原价/优惠/实付各多少 | calculate-price |
| 底座 | 积分余额 + 本月将过期提醒 | query-my-account |

## 三个设计决策

1. **算组合，不只比单券**：单张券"省 11.9"可能不如"满减叠加另一张券"省得多——军师输出的是组合方案，不是券的罗列
2. **每单一张"双面账"**：除了"这单省 X 元"，还告诉你"为了凑单多买了 Y 元"——凑单陷阱一目了然
3. **只读到实付为止**：算完就停，下单由用户在麦当劳官方渠道人工完成。**不碰支付，是红线**

## 快速开始

1. 领 Token：浏览器打开 https://open.mcd.cn/mcp → 手机号 + 验证码登录 → 控制台激活
2. 配 MCP：

```json
{ "mcpServers": { "mcd-mcp": { "type": "streamablehttp", "url": "https://mcp.mcd.cn", "headers": { "Authorization": "Bearer <YOUR_TOKEN>" } } } }
```

3. 导入 Skill：把 `skill_省钱军师.md` 的提示词导入 WorkBuddy 自定义技能，开聊：
   - "50 块钱两个人怎么点最划算"
   - "我这张 11.9 的汉堡券这单用值不值"
   - "帮我看看这单能叠几张优惠"
